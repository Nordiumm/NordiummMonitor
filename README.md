# Nordiumm Monitor

A lightweight server monitoring system written in Rust.

Nordiumm Monitor is designed to monitor multiple servers and collect useful status information such as:

- Online/offline status
- Player count
- Server version
- Latency
- Uptime
- Server information

The project is currently in development.

## Supported Servers

Currently supported:

- Minecraft Java Edition

## Tech Stack

- Rust
- Tokio
- rust-mc-status

## Project Status

🚧 **In development**

The monitoring system is currently being built from the ground up. Future plans include multiple server support, uptime tracking, historical status data, and a web-based status dashboard.
